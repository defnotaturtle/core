# Core Canvas Starter

A minimal HTML5, CSS, and JavaScript project with a canvas that displays "Hello World".

## Files
- [index.html](index.html) — page structure
- [styles.css](styles.css) — styling and layout
- [script.js](script.js) — canvas drawing and animation
- [serve.sh](serve.sh) — local development server script

## Run locally
From the project folder, start a local server:

```bash
./serve.sh
```

Then open:

```text
http://localhost:8000
```

## Features
- Responsive canvas sizing
- Modern dark glassmorphism styling
- Animated Hello World text
- Easy to extend for games, visuals, and experiments
